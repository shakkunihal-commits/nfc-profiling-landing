# NFC Profiling Landing Page

A modern, responsive landing page for an NFC (Near Field Communication) profiling business.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Services Showcase**: Highlight your NFC solutions and offerings
- **Contact Form**: Easy way for customers to get in touch
- **Smooth Navigation**: Fast page navigation with scroll-to-sections
- **SEO Friendly**: Semantic HTML structure

## Structure

- `index.html` - Main landing page
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features and smooth scrolling

## Sections

1. **Navigation Bar** - Fixed navbar with smooth scrolling
2. **Hero Section** - Eye-catching intro with main CTA button
3. **Services** - 6 key service cards with icons
4. **How It Works** - 4-step process flow
5. **Benefits** - Why customers should choose NFC Profiling
6. **Contact** - Get in touch form
7. **Footer** - Links and copyright

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0066cc;      /* Main blue */
    --secondary-color: #1a1a2e;    /* Dark navy */
    --accent-color: #00d4ff;       /* Cyan accent */
    --light-bg: #f5f7fa;           /* Light gray background */
}
```

### Content
Update text content directly in `index.html`:
- Modify service descriptions in `.service-card` elements
- Change step descriptions in `.step` elements
- Update benefit items
- Customize form fields
